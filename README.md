# Claude Content Studio

Skills for creating content with Claude Code: educational videos, presentations, reels, and more.

## Skills

| Skill | What it does |
|---|---|
| [educational-explainer-video](educational-explainer-video/SKILL.md) | Builds vertical 9:16 explainer videos with code: stop-motion scenes in React, AI-voiced title cards, music, a recording script for your own narration, and an interactive web version. |

Coming soon: a presentations skill.

## Installation

- **One project:** copy the skill folder into `.claude/skills/` inside that project.
- **All your sessions:** copy the skill folder into `~/.claude/skills/`.

## Usage

Describe the content you want (topic, audience, platform). The skill starts with a short discovery interview before writing the script or building anything.
